2. HOW TO CONVERT INTO AN ANDROID APK / AAB FOR GOOGLE PLAY STORE:
--------------------------------------------------------------------------------
You have 3 easy, zero-code industry standard ways to generate the Google Play APK:

OPTION A: PWABuilder (Fastest - 100% Free by Microsoft)
1. Upload this `digifestive_maker_app` folder to any free hosting (Netlify / Vercel / GitHub Pages / Hostinger).
2. Go to: https://www.pwabuilder.com
3. Enter your website URL and click "Start".
4. It will read `manifest.json` and generate an Android `.AAB` (Android App Bundle) package signed for Google Play Store!
5. Download the package and upload it directly to your Google Play Console account.

OPTION B: Bubblewrap CLI (Official Google Tool)
1. Run: `npm i -g @bubblewrap/cli`
2. Run: `bubblewrap init --manifest=https://yourdomain.com/manifest.json`
3. Run: `bubblewrap build` -> Gives you `app-release-signed.apk` and `.aab`.

OPTION C: Capacitor / Cordova Wrapper (Offline Local Build)
- Wrap this web app into an Android Studio project via Capacitor:
  `npm install @capacitor/core @capacitor/cli @capacitor/android`
  `npx cap init DigiFestiveMaker com.digigoindia.festivemaker`
  `npx cap add android`
  `npx cap open android` -> Build APK in Android Studio!
